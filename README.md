# Dr.-Tran-Quang-Nhu-lab---robotic-arm-playing-chess-via-computer-vision
This is one of my project while work for Dr. Tran Quang Nhu (Vietnamese-German University PhD). This is about using coputer vision (YOLO) to check for chess pieces. The data will be transfer to Stock Fish engine in order to move the physical pieces via a robotic arm.
